# hedera-agent-passport

> `scaffold-hbar` template: mint an on-chain passport for an AI agent on Hedera — an ERC-721 identity contract plus an append-only attestation log, wired to a tiny Hono API.

```
npm create scaffold-hbar@latest my-agent-passport -- --template buidl25/template-hedera-agent-passport
```

Work in progress — see AGENTS.md for layout.
