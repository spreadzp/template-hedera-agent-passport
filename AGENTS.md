# AGENTS.md

Guide for AI coding agents working in this repo.

## What this is

A `scaffold-hbar` template: AI-agent "passport" on Hedera testnet —
ERC-721 NFT (`AgentPassportNFT`) + append-only event log (`AgentEventLog`)
deployed via Hardhat on HSCS/EVM (chainId 296), wrapped by a Hono API.

## Layout

- `packages/hardhat/` — Solidity contracts, deploy + smoke scripts, vitest.
  - `hardhat.config.ts` — `hederaTestnet` (chainId 296,
    `https://testnet.hashio.io/api`), `hederaMainnet` (295), local `hardhat` (EDR).
  - `scripts/deploy.ts` — deploys both contracts, calls `setWriter(passport)`,
    writes `packages/app/deployedContracts.ts` + appends `PASSPORT_CONTRACT` /
    `EVENTLOG_CONTRACT` to repo-root `.env`.
  - `scripts/smoke.ts` — mints a passport and writes `DEPLOYMENTS.md`
    with Hashscan links.
- `packages/app/` — Hono API (`src/index.ts`), viem client setup
  (`src/hedera.ts` — chain defs, ABI surface, env loading), static UI
  (`public/index.html`), generated `deployedContracts.ts`.
- `template.json` — create-scaffold-hbar manifest (schema: `name`,
  `create-scaffold-hbar.capabilities/defaults/envVars/outro`; enums —
  frontend `nextjs-app|none`, solidityFramework `hardhat|foundry|none`,
  packageManager `yarn|npm|none`).
- `DEPLOYMENTS.md` — testnet addresses + tx hashes (regenerated by smoke).
- `.env.example` — every variable documented; real `.env` is gitignored.

## Commands

- `npm install` — install all workspaces.
- `npm run deploy` — deploy contracts to Hedera testnet (needs `.env`).
- `npm run smoke` — mint + regenerate `DEPLOYMENTS.md`.
- `npm run dev` — API + UI on http://localhost:3000.
- `npm test` — runs vitest in `packages/hardhat` (local EDR, offline).
- `npm run build` / `npm run lint` — `tsc --noEmit` fan-out.
- `npm run format` — prettier write.

## Conventions & landmines

- **Secrets**: only via `.env` (gitignored). Never commit keys. The repo
  must stay trufflehog-clean — check before every commit.
- **ECDSA only**: Hashio JSON-RPC signs with secp256k1. ED25519 operator
  keys will NOT work for deploy/mint.
- **`writer` permission on AgentEventLog**: after deploy, `writer` is the
  *passport contract*, not the operator EOA. Direct `emitTopic` from an
  EOA reverts `NotWriter()` — go through `passport.attestSnapshot` /
  `mint` / `revoke` instead (they emit internally).
- **dotenv load order**: `packages/app/src/hedera.ts` loads `.env` at
  module top — env vars MUST be read after that import runs. Don't move
  env reads into module scope of files imported before `hedera.ts`.
- **viem `write.*`**: on a real network it resolves with the tx hash —
  use `waitForTransactionReceipt` before asserting status or reading
  mutated state (see `scripts/deploy.ts`, `routes` in `app/src/index.ts`).
- **Hardhat 3 `network.connect()`**: each call is a fresh EDR chain in
  tests — share ONE connection inside `describe.beforeAll`, never
  reconnect inside `it()`.
- **Hashscan link format**: `https://hashscan.io/testnet/transaction/<tx>`
  / `/contract/<addr>`. Always return these in API responses — the bounty
  rubric rewards verifiable transactions.
- Testnet only by default; `HEDERA_NETWORK=mainnet` flips chain+RPC+links.

## Where to change things

- New contract logic → `packages/hardhat/contracts/` + a test in
  `packages/hardhat/test/` (offline EDR).
- New API surface → `packages/app/src/index.ts`; shared chain/ABI setup
  belongs in `src/hedera.ts`.
- Scaffold-time UX (env prompts, outro) → `template.json` — keep the
  schema enums valid or `npm create` rejects the manifest.
